# Flood Risk Prediction API

A backend API service for flood risk prediction using address-based and division-based lookup.  
This API is designed for reusable company-level integrations and includes ML model prediction results in the response.

The system provides two backend endpoints:

- Address-based flood risk prediction
- Division-based flood risk prediction

API documentation and testing are available through Swagger UI.

---

## Features

- Address-based flood risk lookup
- Division / administrative area-based flood risk lookup
- ML model prediction result included in API response
- Structured JSON response format
- Swagger/OpenAPI documentation
- Backend-only implementation
- Input validation
- Error handling
- Reusable API structure for company integrations
